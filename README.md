# nairobitransit
A web-based public transportation management system designed to help
Nairobi commuters discover routes, stops and fares while allowing
administrators to manage transit information.

## Features

- Passenger route planning
- Google Maps integration
- Route management
- Stop management
- Fare management
- Administrator authentication
- Admin dashboard
- Passenger portal
- About and Contact pages

## Technologies

- React
- Vite
- Tailwind CSS
- Flask
- SQLAlchemy
- SQLite
- Google Maps API
